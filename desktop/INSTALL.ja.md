# bizencore terminal デスクトップ版

macOS 13以降・Apple Silicon（M1以降）向けです。Intel Mac、Windows、Linuxは
現在の配布対象ではありません。最低OS要件はElectron 44の要件であり、全バージョン
のMacで検証済みという意味ではありません。

## 配布元と制限

配布ページは https://bizencore.com/downloads/ です。候補をビルドしただけでは
公開されません。公開済みと表示されている版だけをダウンロードしてください。
Apple Developer Programには加入しておらず、Developer ID署名・Appleの公証は
受けていません。ad-hoc署名の整合性検査はAppleによる安全性確認ではありません。
macOSが起動をブロックする可能性があります。

## 開いている版を確認する

0.1.9以降は、画面左上のロゴの横とアプリメニューにバージョンが表示されます。
Previewは開発版です。アプリメニューの「このアプリをFinderで表示」で、
起動中の本体の場所を確認できます。旧版のバックアップやビルド結果と区別し、
普段はインストールした本体を開いてください。更新後も古い版は自動削除しません。
0.1.12以降は同じ製品版を重ねて起動すると、起動済みの画面へ戻ります。以前の版は
この制御に対応していないため、バックアップの旧版と新版を同時に開かないでください。

## 画面の分割

0.1.10以降は、エージェント欄の分割アイコンから左右・上下を切り替えられます。
上下分割ではタスク一覧が上、ターミナルが下になります。詳細パネルは上段の一覧の
隣に開きます。境界はドラッグ、または境界にフォーカスして矢印キーで調整できます。
方向とそれぞれの比率はアカウント・接続先ごとに保存され、切り替えても起動中の
エージェントを再起動しません。

## 起動できないとき

- CLIが見つからない場合は、公式のインストール案内から導入し「診断を更新」で
  再確認します。アプリが勝手にCLIのインストールやログインをすることはありません。
- 診断が失敗している間は起動できません。表示されたインストール先を確認してください。
- 作業フォルダがなくなった、またはアクセスできない場合は、利用できるフォルダを
  選び直します。必要な場合だけmacOSのアプリ個別の許可を確認してください。
  保護設定の無効化や、広範囲の権限変更は不要です。

## インストール

1. 公式ページからZIP・SHA256SUMS・変更履歴を取得します。
2. ターミナルで `shasum -a 256 ダウンロードしたZIPのパス` を実行し、SHA256SUMSと
   完全一致することを確認します。不一致なら起動せず、取得し直してください。
3. ZIPを展開し、bizencore terminal.appをアプリケーションフォルダへ移します。
4. アプリを開き、bizencoreにサインインします。
5. Claude Code / Codexを別途インストール・認証し、アプリの診断で確認します。
6. エージェントと作業フォルダを選び、明示的に起動します。タスクの担当は任意です。

起動がブロックされた場合は、安全性を確認できないものを開かないでください。
配布元・チェックサム・未公証の制限を理解し、このアプリだけを許可すると判断した
場合は、Appleの案内に従い、ご自身で許可と本人認証を行ってください。
https://support.apple.com/ja-jp/102445
OS全体の保護を無効化したり、隔離属性を削除する必要はありません。

## 更新

対応版では新版公開後にヘッダー右上の更新アイコンが現れ、配布ページを開きます。
自動インストール・作業中の強制終了は行いません。0.1.7以前は手動で確認します。

1. 作業を終えるかエージェントを停止し、Cmd+Qで完全終了します。
   ウィンドウを閉じるだけではアプリやエージェントは終了しません。
2. 新版のチェックサムを確認し、別の場所へ展開します。
3. 旧版アプリを保管してから、新版を同じ場所へ入れ替えます。
4. 認証・タスク・設定を確認します。ペインは自動で起動しません。
5. 更新版でもmacOSが個別の許可を求める場合があります。

問題があれば完全終了後に旧版へ戻します。データ形式変更がある版は変更履歴の
互換性案内に従ってください。保存データを削除して直す操作は推奨しません。

## 認証・権限・データ

認証はClerk、タスクと添付の同期はConvexを使います。認証トークンはmacOSの
暗号化機能を使って端末に保存します。作業フォルダ・配置・会話の紐付けなども
端末に保存されます。端末内のすべての作業データが暗号化されるわけではありません。

CLIはご自身の認証・契約・許可設定で動き、ファイルの読み書きやコマンド実行が
可能です。一般CLI全体の権限をbizencoreが自動的に保証・制限するものではありません。
サインアウトはbizencoreをロックし、このアプリのエージェントを停止しますが、
各CLIからのサインアウトやアンインストールは行いません。

更新確認にアカウントトークン・タスク・フォルダ・会話を送る設計ではありません。
認証SDKや表示フォントなど、外部サービスとの通信は別にあります。

## 問題が起きたら

- 認証確認で止まる: 通信と、背後のmacOS本人認証・キーチェーンのダイアログを
  確認し、再読み込みします。macOSの認証はご本人で行ってください。
  0.1.12以降はキーチェーン待ちを本体から分離しており、待機中でも終了できます。
  未公証/ad-hoc署名のため、更新のたびに確認が必要になる可能性は残ります。
- CLIが見つからない: 診断に従い、各CLIを別途導入してください。自動導入しません。
- フォルダを開けない: 選んだフォルダとOS/CLIの権限を確認します。権限を一括で
  広げるのではなく、必要なフォルダだけを指定してください。
- 接続が切れた: 完了したと決めつけず、同期状態と実際のタスクを確認します。

報告先: https://github.com/bizen/bizencore-os/issues
バージョン、macOS、Macの種類、再現手順、エラーを添えてください。公開Issuesに
認証トークン・秘密鍵・メールアドレス・個人のタスク/会話・ローカルパスを含む
スクリーンショットやログをそのまま投稿しないでください。

同梱ライブラリの表記はTHIRD_PARTY_NOTICES.txtと、アプリ内のElectronの表記を
確認してください。
