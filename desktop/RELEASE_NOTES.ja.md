# 0.1.8 配布準備用候補

これは公開済みリリースの告知ではありません。実機受入れと素材の配布条件の確認が
終わるまで、ダウンロード公開・公開済み更新通知を有効にしません。

## 変更

- 最新のWeb版を基点に、デスクトップの共有タスク画面を整理。
- デスクトップ内のタスク列幅に合わせた目次、現在地、ラベルへの移動。
- タスクへのリンク・複数ファイルのドラッグ＆ドロップ添付。
- 0.1.7で見つかったファイル添付通信のCSP不具合を修正。決められたConvexの
  ファイルアップロード先だけを許可し、任意の接続先へは広げない。
- ヘッダー右上に公開済み新版の通知。押すと公式配布ページを開く。
- ネイティブメニューからも手動更新の案内と配布ページへ移動。
- アプリの自動入れ替え、作業中の強制停止、CLIの自動起動はしない。
- 既存の通常CLIペインでのオーケストレーションと作業設定を維持。
- コミット済みソースからのリリースビルドと、配布物へのソースコミット記録。
- 日本語の導入・更新・復旧・権限/データ・報告先の案内と依存表記の同梱。
- 再配布許可のない3枚のイラストをデスクトップ配布物から除外。
  起動画面はロゴのみ、クエスト種別はLucideのアイコンへ変更。Web版は変更しない。
- Electron・Chromium・依存ライブラリのライセンス表記を読み取り可能な形で同梱。

## 要件と既知の制限

- macOS 13以降、Apple Silicon。ほかのOS/Intel Macは未検証・配布対象外。
- Apple Developer ID署名・公証なし。個別の起動許可が必要になる場合がある。
- 更新時、macOSのキーチェーン等の本人認証が求められる場合がある。
- 0.1.7以前には新版通知がない。初回は手動で新版へ入れ替える。
- 第二のMacがないため、クリーン端末での受入れは未検証。
- 別アカウント・実際のサーバー側認証失効の受入れも未検証として残る。
- 配布前の実機受入れと公開ダウンロード検証は別途必要。

## 互換性

この候補は既存の認証・タスク・ワークスペース保存領域を削除したり、新しい
データ形式へ一括変換したりしません。配置は復元してもエージェントは未起動です。
入れ替え前に旧版を保管し、問題があれば完全終了後に旧版へ戻してください。
